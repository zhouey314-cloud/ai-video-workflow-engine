# AI Video Workflow Engine — 项目贡献与简历素材

按合作问题或岗位选取两三条贡献。这里记录可检查的本地工作流、原创动画和交付证据；不把机械 QA、人工审片与客户验收混成同一件事。

## 可以承担的实现

- 用 Python / FFmpeg 串起素材清单、分镜、时间轴、字幕、真实渲染和 ffprobe / 解码检查，给失败、素材缺口、待审片和批准保留不同状态与退出行为。
- 将渲染结果组织为每任务交付包，保留 MP4、SRT、ASS、时间轴、预览、QA 和输入/输出哈希；在完成检查后发布完整目录，失败时清理本次临时产物并保留已有文件。
- 实现独立的本地交付包校验，拒绝文件缺失、篡改、重复/越界路径、符号链接和未列入清单的文件。文件校验不声称提供来源签名、剪辑质量或人工批准。
- 制作并公开54秒、九镜头的原创程序动画，保留生成源码、原创数学配乐、素材许可、字幕与复现命令。它是程序动画，不是真人口播、数字人效果或客户商业成片。

实现与运行入口：[完整任务包](DELIVERY_BUNDLES.md) · [54秒样片、源码与许可](../examples/original_54s/README.md) · [流程架构](architecture.md) · [完整案例](case-study.md)。

## 可直接采用的贡献表述

> 实现从素材、时间轴、字幕到 FFmpeg 渲染与媒体检查的本地工作流，补齐可校验交付包和失败回收；交付成片、检查记录及复跑命令，并保留独立人工审片入口。

若需要强调内容与工程结合，可再补一条：

> 用原创程序动画和数学合成配乐完成54秒、九镜头样片，把分镜、字幕、素材来源、渲染和 QA 连成可追溯示例；作品展示批准绑定确切文件，后续输出重新审片。

## 合作与验收边界

适合处理已有授权素材的重复导出、字幕/时间轴一致性及可复跑交接。具体业务需先确认素材权利、字体、运行环境、质量标准和审片责任；生产任务队列、真实客户素材和发布集成另行约定。

机械 QA 测量完整解码、时长/流、至少0.30秒的黑场、sample peak，以及2fps采样的字幕层像素边界。这些检查不能代替全片可读性、节奏、内容和审美判断。`HUMAN_REVIEW` 表示等待人工审片；不自动变成 `APPROVED`。

未接入付费视频模型或真人声音，没有生成式视频质量、客户投产、商业效果或平台发布验收。新渲染不会继承历史样片的批准；公开来源与素材仍按各自许可使用。
