# Release notes template

Complete from a tested commit. Delete placeholder prompts before publication; never infer model, human, or customer acceptance from tests.

## Added

- Describe implemented additions and evidence.

## Changed

- Describe changed behavior and compatibility.

## Fixed

- Link reproducible defects and regression checks.

## Verification

- List commands, CI run, media inspection, and human review result separately.

## Known Limitations

- State synthetic, provider, rights, quality, and deployment boundaries.

## Upgrade / Run

- Give exact local prerequisites and commands; describe any migration.
